# Codex-LB Rates

Monitor **Codex-LB** account pools (5-hour, weekly, and monthly remaining) in Home Assistant, with an optional ChatGPT / Codex CLI mode for single accounts (5h / weekly / reset credits).

Reset sensors show `Xd XXh` countdowns. Secrets stay in the config entry. See the [README](https://github.com/uniskela/codex-lb-rates) for setup and Lovelace examples.
