# Codex Rates

Show Codex **5-hour** and **weekly** quota remaining in Home Assistant.

- **Codex-LB** mode: all pooled accounts + pool average gauges
- **ChatGPT / Codex CLI** mode: device-code OAuth, paste-callback, or `auth.json`

Secrets stay in the config entry. See the [README](https://github.com/uniskela/codex-rates) for setup and Lovelace examples.
