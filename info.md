# Codex-LB Rates

Monitor **Codex quota remaining %** (primary) and reset times from a [Codex-LB](https://github.com/soju06/codex-lb) account pool or a single ChatGPT / Codex CLI account. Window labels follow provider-reported durations when available. Optional Configure settings add used-% sensors and rich diagnostics (plan, credits, last refresh, request count). A bundled Lovelace remaining-% card is included. Secrets stay in the config entry. See the [README](https://github.com/uniskela/codex-lb-rates) for setup and dashboard examples.
